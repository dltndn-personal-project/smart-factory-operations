# 예시: Integration Component의 검증 기록

이 파일은 가상 예시다. 실제 검증 결과는 `VALIDATION.md`에 기록한다.

- 검증 조합: `COMPOSITION.json`의 Git commit 또는 PR 링크
- 환경: Docker Compose와 테스트에 사용한 설정
- 실행 명령: `<실제 통합 테스트 명령>`
- 결과: 통과/실패, 실행 일시와 로그 링크
- 연관된 Shared Issue: `<Issue ID 또는 해당 없음>`
- 릴리스 판단: `<검증한 조합의 사용 가능 여부와 근거>`
- 실패 시 복구: `<이전에 검증된 조합의 commit 또는 이미지 digest>`
